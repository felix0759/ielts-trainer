# IELTS Reading Practice Website

A free static IELTS Reading practice website built with HTML, CSS, JavaScript, and JSON.

## Features

- Public static website
- Reading test catalogue
- Computer-based test layout
- 60-minute timer
- True / False / Not Given questions
- Multiple choice questions
- Short-answer questions
- Instant marking
- Answer explanations
- Estimated band range

## How to run locally

Use VS Code Live Server and open `index.html`.

## How to publish

Push these files to GitHub and enable GitHub Pages from the `main` branch and `/root` folder.
